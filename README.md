# soundDB Plugin
This is a plugin for Scratch forks (like **Turbowarp** and **PenguinMod**).
It utilises a app audio capturing API (Heh, AAC just like the audio codec) but it only works on **WEB BROWSERS**!!

The most compatible browser is **Chrome** or **Chromium (it's better either way)** and Edge.

Any PWA fork (like PenguinMod in a PWA app or Turbowarp in a PWA app) will work no problem.
Turbowarp Desktop does not work because it doesn't use PWA or WebViewII (Edge) to let you render the (Choose app to capture sound...) dialog.
